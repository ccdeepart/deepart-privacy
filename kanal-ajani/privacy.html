Privacy Policy

Kanal Ajani · Last updated: 5 November 2026

Kanal Ajani is a private tool. It is used only by its owner, on their own computer, for YouTube channels they own.

What it accesses

With the channel owner's permission, it uses the YouTube Data API and YouTube Analytics API to read the owner's channel information, videos, statistics and comments. It can also make changes to the owner's channel, only when the owner approves them.

How data is used and stored

  • Data is used only to help the owner understand and manage their own channels.
  • Access keys are stored only on the owner's computer, in files only the owner can read.
  • When the owner asks for an analysis, the data needed for it is processed by the owner's AI assistant, Claude by Anthropic.
  • Data is not sold, used for advertising, or shared with anyone else.
  • The tool does not collect data about other people, apart from the public comments and anonymous statistics that YouTube provides for the owner's channel.

YouTube and Google

This tool uses YouTube API Services. See the YouTube Terms of Service and the Google Privacy Policy. Access can be removed at any time from the Google account connections page.
